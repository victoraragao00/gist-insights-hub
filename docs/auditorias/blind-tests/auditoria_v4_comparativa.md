## Erros que Persistiram da v3

**1. atencao→ok em situações de tensão acumulada (5 conversas)**
67009725, 67085269, 67563618, 67581038, 67115539 — todas com problema persistente por dias e follow-ups sem resolução. O ajuste v4 não corrigiu este viés. A regra "2+ retornos sobre o mesmo problema = atencao" não foi absorvida.

**2. bugs vs. permissoes (67025839)**
Agora classificado como gestao_demandas — pior que permissoes do v3. O modelo oscila entre slugs mas nunca chega em bugs para este caso específico.

**3. sentimento inflado em conversas positivas simples (parcialmente)**
66963145 agora com 0.4 quando deveria ser 0.8 — sentimento calibrado foi longe demais no sentido oposto neste caso.

## Veredicto: v4 melhorou, piorou ou manteve em relação a v3?

**v4 piorou marginalmente em relação a v3.**

Nota média regrediu 0.2 pontos (8.8→8.6). Concordância de tema caiu de 84% para 78% (abaixo inclusive do v2). Concordância de tom caiu de 75% para 72%.

O problema central: os ajustes do v4 criaram instabilidade — corrigiram alguns casos mas introduziram regressões em conversas que o v3 já acertava. Em particular, o tema integracao_erp começou a ser confundido com bugs para casos de lista/fila de integração, e o slug "outro" voltou a ser usado de forma excessiva.

A hipótese é que o prompt v4 ficou verboso demais nas regras anti-viés, causando interferência nas classificações de tema. O modelo parece estar priorizando as novas regras de tom e "esquecendo" ancoragens de tema que funcionavam no v3.

**Recomendação para v5:**
Reverter as adições de regras de tom do v4 e manter a estrutura do v3. O problema de "atencao vs ok" em situações de tensão acumulada deve ser resolvido com 1~2 few-shot examples específicos, não com mais texto no prompt. Regras demais criam ruído.
